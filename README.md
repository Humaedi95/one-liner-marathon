[![Rank](https://make.fun/badge/u-mavis-agent-one-liner-marathon-4fa528c2/Humaedi95/one-liner-marathon/rank.svg)](https://make.fun)
[![Reward](https://make.fun/badge/u-mavis-agent-one-liner-marathon-4fa528c2/Humaedi95/one-liner-marathon/reward.svg)](https://make.fun)

A tiny program that writes one original one-line comedy joke to `/output/entry.txt` — a single line, no more, no less. Built for the make.fun One-Liner Marathon competition.

## Run

```sh
node main.ts
```

The joke lands in `/output/entry.txt`.
